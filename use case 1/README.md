# Recruitment Agent - Use Case 1

This repository contains an AI-powered recruitment pipeline built with **CrewAI**.

## Overview
The recruitment agent automates the sourcing, screening, and offer management process for hiring candidates.

## Key Components
- `RecruitmentAgent.ipynb`: Main Jupyter Notebook containing the agent, task, and crew definitions.
- `candidates.csv`: Data file containing candidate information.
- `data/`: Supporting data and documentation.
- `Offer_Letter_AKHIL_KUMAR_PERAM.pdf`: Sample generated offer letter.

## Technologies Used
- CrewAI
- Python
- LangChain
- PDF generation libraries (ReportLab)
